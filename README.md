A standalone professional portfolio website for Justice Fuller.

- About
- Projects

- Skills
- Certifications

## Run locally
Open `index.html` in a browser.

## Publish
This is a static site and can be hosted on Netlify, Cloudflare Pages, GitHub Pages, or another static host. A custom domain can be connected later.
